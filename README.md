# ⚡ GRIT Team Growth & Work OS

Engineered with a **Dual-Engine Architecture**: combining high-velocity team sprint delivery with a dedicated **Personal Growth OS**, complete past history database archive, daily standup reflections, and accountability.

## 🎯 Navigation & Core Modules

1. **🏆 Team Dashboard & Leaderboard**:
   - **Team Standings & Leaderboard**: Live team hours aggregate, active punch-ins, tasks progress, and ranked score cards (#1 Top Performer, #2 Contender, etc.).
   - **Team Daily Learnings & Activity Feed**: Public feed visible to everyone showing each member's daily standup submission ("What they learned today", deliverables completed, hours worked, and team blockers).

2. **📈 Personal Growth OS (Dedicated Separate Module)**:
   - **⚡ Today's Work & Focus ("Aaj Ye Kiya Tha")**:
     - Active focus session stopwatch timer and today's logged hours.
     - **🎯 My Growth Targets & Upcoming Action Plan ("Kya Karne Wale Hain")**: Interactive personal goal-setting engine. Add new target skills, sprint deadlines, execution strategies, and mark them completed.
     - **📊 7-Day Focus Trend Chart**: Interactive daily hours chart.
   - **🗺️ My Skills & Where I Stand ("Kya Kya Seekha" & Active Standing)**:
     - High-level KPIs: Total Mastered Milestones, Active Tracks In Progress, Fully Mastered Tracks.
     - Quick Search and Domain Category filter.
     - **Interactive Clickable Expanders for every track**:
       - **✅ Kya Kya Seekha**: Complete list of mastered milestones with uncheck/revisit controls.
       - **⏳ Where I Stand / Next Up**: Interactive checkboxes for remaining milestones. Checking any milestone immediately awards +100 XP, updates SQLite, and triggers celebration toast!
       - **📚 Curated Learning Blueprint**: In-depth concepts to study, free official documentation links, and recommended proof-of-work capstone project.
   - **🗄️ Past History Database (Complete Archive)**:
     - **Past Daily Standups Archive**: Filterable archive of all past daily reflections and learnings.
     - **Past Work Sessions Log**: Complete table of all past sessions, start/end timestamps, duration, and focus notes.

3. **🗺️ Skill Roadmaps & Growth (15+ Comprehensive Technical Tracks)**:
   - **Exhaustive Domain Catalog Covering Every Major Discipline**:
     1. `🤖 AI Engineering & Generative AI Systems` (LLMs, RAG, LangGraph, Vector DBs, vLLM)
     2. `🧠 Machine Learning & Deep Learning` (PyTorch, CNNs, Transformers, XGBoost)
     3. `🔬 Data Science & Scientific Computing` (NumPy, Pandas, EDA, Statistical A/B Testing)
     4. `📈 Data Analytics & Business Intelligence` (SQL Analytics, Power BI/Tableau, Cohorts, KPIs)
     5. `🗄️ SQL Mastery & Database Architecture` (Indexing, EXPLAIN, Window Functions, ACID, WAL)
     6. `🐍 Python Engineering Mastery` (OOP, Generators, AsyncIO, FastAPI, Testing)
     7. `🌐 Full-Stack Web Development` (HTML5, Modern CSS, React/Next.js, REST APIs)
     8. `🎨 Modern Cyber UI/UX & Frontend` (Design Tokens, Glassmorphism, Animations, WCAG)
     9. `⚙️ Backend & Distributed Systems Architecture` (gRPC, Redis, Kafka, Rate Limiting, CAP)
     10. `☁️ Cloud DevOps & Kubernetes Infrastructure` (Docker, K8s Ingress, Terraform, CI/CD)
     11. `🔄 Data Engineering & Modern ELT Pipelines` (dbt, Airflow, Spark, Kimball Modeling)
     12. `🛡️ Cybersecurity & Ethical Defense` (OWASP Top 10, Wireshark, Cryptography, IAM)
     13. `📱 Mobile App Development (Flutter & React Native)` (Dart, State Management, SQLite)
     14. `⚡ AI Agents & Intelligent Systems` (Function Calling, Multi-Agent Loops, Benchmarking)
     15. `🎯 Product, Strategy & Client Operations` (Client Discovery, Sprints, Code Review)
   - **Instant Search & Domain Category Filtering**: Find any skill, concept, or tool in milliseconds.
   - **"Kahan Se Kya Lagta Hai" Curated Guides**: Free documentation links, core concepts, and capstone project blueprints.
   - **Phased Milestones**: Checklists organized by Foundations, Core Engineering, and Production Mastery.
   - **Add Custom Roadmap**: Build personal tracks with custom milestones.
   - **Log Learning Sprint**: Record GitHub repos, proof of work, and hours.

4. **📋 Tasks Board**:
   - **🔍 Instant Deliverables Search**: Real-time keyword filter across deliverable title, description, and category.
   - **⏱️ Live Stopwatch Timer & Task Sessions**: Track active deep work with single-click start/stop and SQLite-backed session logs.
   - Sprint task assignment for Lead (Rajat) and personalized kanban cards with 1-click status transitions (`Pending` ➔ `In Progress` ➔ `Under Review` ➔ `Completed`).

5. **🔥 Daily Consistency Streak & Social Feedback**:
   - **🔥 Consecutive Day Streak**: Real-time calculation from daily checkouts and work sessions, displayed in Personal Growth OS (Hero + KPI), Sidebar user card, and Leaderboard.
   - **👏 Team Kudos Reaction**: Interactive button on daily feed cards awarding immediate appreciation for teammate learnings.
   - **⚡ Standup Autofill**: Automatically pre-fills evening checkout modal with the active session's deliverable note so engineers don't re-type work.
   - **🎯 Punch-In Task Quick-Picker**: Choose an assigned sprint task directly from the dropdown to focus without manual typing.

6. **💡 Academics Hub**:
   - Engineering discussion forum with markdown syntax-highlighted code snippets and solution threads.

7. **👑 Admin Controls (Lead & Multiple Admins)**:
   - **👥 Manage & Edit Team Members**: Edit member full name, role title/specialization, contact number, avatar color, or promote members to Admin (e.g., Shatakshi or others as second Admin).
   - **🎯 Manage Skills & Roadmaps**: Publish brand-new engineering/business tracks directly to the team's shared curriculum with custom milestone topics (+100 XP each).
   - **➕ Provision New Members**: Add custom team members with designated roles, specializations, initial credentials, and phone numbers.
   - **🔐 Team Password Quick-Reset**: 1-click password resets for any team member.
   - **🗄️ Database Maintenance & Audit**: Comprehensive SQLite schema inspection and footprint audit.

8. **🔐 Self-Service Password Management**:
   - Every team member can securely update their personal password anytime from the sidebar (`🔐 Change My Password`).
